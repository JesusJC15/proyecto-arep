# Checklists finales AREP

## Checklist tecnico

- `docker compose up --build -d` funciona
- frontend responde en `http://localhost:4173`
- backend responde en `http://localhost:8000/ready`
- `rag/status` devuelve corpus, indice y proveedor
- login paciente y profesional funcionan
- flujo E2E completo funciona
- pruebas backend pasan
- build frontend pasa

## Checklist demo

- runbook validado
- guion de demo de 5 a 8 minutos listo
- usuarios demo conocidos
- caso semilla disponible
- comandos de recuperacion preparados
- pestañas y endpoints de respaldo abiertos

## Checklist academico

- paper alineado con implementacion real
- diagramas alineados con compose y blueprint AWS
- trazabilidad requisito -> implementacion -> evidencia documentada
- limites y amenazas a la validez explicitados
- metricas RAG incluidas
- slides HTML listas para sustentar

## Checklist de proyeccion productiva

- blueprint AWS base documentado
- Compose mapeado a target cloud
- variables de entorno documentadas
- observabilidad minima documentada
- trabajo futuro y limites de produccion explicitados
