# Base de conocimiento Fase 3

Este directorio contiene el corpus clinico curado para el pipeline RAG academico de AREP.

## Contenido

- `corpus-manifest.json`: catalogo versionado de documentos y metadatos obligatorios.
- `curation-policy.md`: criterios de inclusion, exclusion y uso academico.
- `clinical-guidelines/`: documentos curados para triage, red flags, autocuidado y escenarios clinicos de demo.
- `evaluation/rag-evaluation-dataset.json`: dataset minimo para validar retrieval y cobertura documental.

## Principios

- Uso academico y demostrativo.
- No sustituye validacion clinica formal ni guias asistenciales oficiales.
- La recuperacion documental debe ser trazable, reproducible y evaluable.
- El corpus se versiona para alinear codigo, paper y evidencia de evaluacion.
